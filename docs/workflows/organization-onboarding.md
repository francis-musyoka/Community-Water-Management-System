# Organization onboarding workflow

1. The platform admin creates the organization, sets its type and subscription plan, and creates the first org admin.
2. The org admin sets up schemes, locations, zones or buildings, and each scheme's Paybill.
3. The org admin sets tariffs (price per unit for each connection type, standing fee, flat rate), reading frequency, payment allocation order, and penalty and disconnection rules.
4. The org admin sets the SMS sender name and expense categories.
5. The org admin adds staff, assigns roles, and assigns them to schemes and routes.
6. The org admin (or platform admin) downloads the Excel template, fills in customers, connections, meters, last readings, and opening balances, and uploads it.
7. The system checks the file. Errors are fixed and the file re-uploaded until it is clean.
8. Records are created. Customers receive SMS verification codes.
9. Field officers upload contracts. Missing contracts appear in the customer compliance report.
10. The first reading cycle produces the first bills.

## Exceptions to define

- The Paybill is not yet available when the organization wants to start.
- The organization's records are too incomplete to import.
